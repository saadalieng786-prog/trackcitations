🔴 Technical Issues — Ranked by Impact
🗃️
Cache Lifetimes Not Configured — Est. savings: 10,723 KiB
Static assets (images, JS, CSS) have no browser caching headers set. Every visitor re-downloads 10+ MB of assets each visit. This is the #1 cause of the catastrophic 55.9s LCP score on mobile.
Set Cache-Control headers with max-age of 31536000 for static assets. Use a CDN like Cloudflare.
Critical
🚧
Render-Blocking Requests — Est. savings: 1,560ms
JavaScript and CSS files are blocking the browser from rendering the page. Users see a blank screen for 1.5+ seconds before any content appears. This directly causes the 9.2s FCP (First Contentful Paint).
Defer non-critical JavaScript. Load CSS asynchronously. Move scripts to bottom of <body> tag.
Critical
🖼️
Unoptimized Images — Est. savings: 224 KiB
Images are being served in legacy formats (PNG/JPEG) from 2018 uploads. No WebP/AVIF conversion, no lazy loading on all images, no srcset for responsive sizes. The hero video background also adds significant load weight.
Convert all images to WebP. Use the <img loading="lazy"> attribute. Implement srcset for different screen sizes.
Critical
📐
Layout Shift Culprits (CLS: 0.224)
Elements are shifting position as the page loads (CLS of 0.224, threshold is 0.1). This causes a jarring user experience where content jumps around — a direct Google ranking signal. Likely caused by images without explicit width/height attributes and the logo slider.
Add explicit width and height attributes to all <img> tags. Reserve space for the logo carousel before images load.
Critical
🔄
Forced Reflow Detected
JavaScript code is triggering forced layout reflows — the browser must stop, recalculate layout, then continue. This adds significant time to page rendering and contributes to poor performance on low-end mobile devices.
Audit JavaScript files for DOM reads after DOM writes. Use requestAnimationFrame for animations. Consider WP-Optimize or similar tools.
Critical
🔤
Font Display Issue — Est. savings: 10ms
Web fonts are blocking rendering. When the font file downloads slowly, text remains invisible (FOIT — Flash of Invisible Text). While the savings are small here, it contributes to a poor user perception of speed.
Add font-display: swap to all @font-face declarations. Preload critical fonts in <head>.
Moderate
📵
Viewport Meta Blocks User Zoom (Accessibility Violation)
The page has maximum-scale=1.0, user-scalable=0 in the viewport meta tag. This prevents users from zooming in on mobile — a direct accessibility violation that hurts Google's Accessibility score and can reduce rankings.
Remove user-scalable=0 and maximum-scale=1.0 from the viewport meta tag. Allow natural pinch-to-zoom.
Moderate
🤖
Agentic Browsing Fails (0/2 on Mobile)
AI agents (used by ChatGPT, Perplexity, and Google AI Overviews to browse websites) cannot properly access the site. This is a new but increasingly important signal — AI tools will not recommend or cite a site they can't access.
Ensure proper robots.txt configuration, add structured data, improve page structure for machine readability.
Moderate
03
On-Page SEO — Content & Structure
Page-level issues affecting how Google understands and ranks the site
❌
Homepage H1 Tag is Wrong — Shows "Other Industries"
The homepage H1 tag reads "Other Industries" — which is a completely different page's heading. This is a serious WordPress/theme routing bug. Google reads the H1 as the most important topic signal on the page. Having the wrong H1 tells Google this is a page about "Other Industries," not about CargoTel's core offering.
Fix the page template in WordPress. The homepage H1 should be something like "Industry-Leading Automotive TMS & Logistics Software."
Critical
📝
No Blog or Content Marketing — Zero Content Strategy
CargoTel has no blog, no guides, no case studies, and no educational content. This is the single biggest reason for 28 visitors/month. Competitors who create content on topics like "how to choose automotive TMS software" or "EDI integration for vehicle logistics" are capturing all the organic demand that CargoTel should own.
Launch a blog immediately. Target 2 articles/month on automotive logistics, TMS best practices, EDI guides, and vehicle logistics trends.
Critical
🔍
No Structured Data / Schema Markup
The entire website has zero schema markup (JSON-LD). There is no Organization schema, no SoftwareApplication schema, no FAQ schema, no Review schema. Schema markup helps Google understand the page content and enables rich snippets in search results — which dramatically improve click-through rates.
Add Organization, SoftwareApplication, and FAQPage schema to key pages. This is a relatively easy implementation with major impact.
Critical
🏷️
Thin Content on All Product Pages
Product pages like /automotive-tms/, /yard-compound-management/, and /edi-connectivity-integration/ contain very few words and lack the depth needed to rank for competitive keywords. Google rewards comprehensive, authoritative content. Short pages with no FAQs, no comparisons, no detailed feature explanations, and no use-case descriptions will not rank.
Expand each product page to 1,200+ words. Add FAQs, feature comparisons, use cases, customer pain points, and integration details.
Critical
🔗
Internal Linking Issues — HTTP vs HTTPS Inconsistency
Internal links on subpages (e.g., /automotive-tms/) point to the non-secure HTTP version of the domain. While there is likely a redirect, this creates unnecessary redirect chains that slow down Googlebot crawling and dilute link equity. This was observed on multiple product pages.
Update all internal links to use the secure HTTPS version of the domain. Check and fix the links in the website settings and content.
Moderate
📊
No Google Search Console or Analytics Verified (Inferred)
With only 28 monthly visitors and no blog/tracking signals visible, there are likely gaps in performance monitoring. Without proper Search Console verification and a clear analytics setup, it is impossible to detect indexing issues, manual penalties, or crawl errors before they impact rankings.
Verify Google Search Console. Set up Google Analytics 4. Submit XML sitemap. Monitor Coverage and Core Web Vitals reports weekly.
Moderate
📱
Video Background on Hero Section
The homepage uses a .mp4 video file as a background element. On mobile, this video either fails to load (blank) or uses excessive bandwidth. The video is also not contributing to SEO value. It is a significant contributor to the 9.2s FCP on mobile.
Replace the hero video with a static, optimized WebP image on mobile. Load the video only on desktop using CSS media queries.
Moderate
✅
Meta Description is Present (But Needs Improvement)
The website has a meta description: "Leading Automotive TMS, YMS, EDI, EPOD, and wireless solutions provider for carriers, brokers, and logistics providers." This is good — but it's very technical and does not include clear calls-to-action or differentiation from competitors.
OK
✅
HTTPS/SSL is Active
The website correctly redirects to HTTPS and has a valid SSL certificate. This is a basic but essential ranking signal that is in place.
Good
